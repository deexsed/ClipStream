# Техническое задание (ТЗ): ClipStream — Агрегатор игровых хайлайтов

## 1. Общее описание проекта
**ClipStream** — это веб-платформа, предназначенная для просмотра коротких игровых клипов (Twitch Clips) в формате вертикального бесконечного скролла. Контент агрегируется автоматически через Twitch API. Видеоконтент встраивается через официальный Twitch Embed.

## 2. Цели и задачи
- **Для зрителей:** Предоставить удобный интерфейс для быстрого просмотра игрового контента, персонализированную ленту и возможность взаимодействия с сообществом.
- **Для стримеров:** Создать дополнительную точку входа для аудитории и систему репутации.
- **Для администратора:** Инструменты монетизации и управления контентом.

## 3. Архитектура системы
Система состоит из следующих компонентов:
1.  **Frontend (React):** Пользовательский интерфейс, логика плеера, профили пользователей.
2.  **Backend (C++ / Boost.Beast):** Высокопроизводительный сервер для обработки API запросов, интеграции с Twitch и управления БД.
3.  **Database (MySQL):** Хранение метаданных клипов, данных пользователей, комментариев и связей (подписки, лайки).
4.  **Cache (Redis):** Кэширование популярных клипов и сессий.

## 4. Стек технологий
-   **Frontend:** React, Tailwind CSS, Lucide React (иконки).
-   **Backend:** C++ (Boost.Beast, nlohmann/json, pqxx для PostgreSQL).
-   **БД:** MySQL
-   **Кэш:** Redis 7+.
-   **DevOps:** Docker, Docker Compose, Nginx.

## 5. Функциональные требования

### 5.1. Пользователи и Профили
-   **Авторизация:** Регистрация и вход (OAuth Twitch или стандартная почта/пароль).
-   **Профиль пользователя:**
    -   Возможность смены аватара.
    -   Список подписок на каналы/авторов.
    -   История просмотров и понравившиеся клипы.
-   **Подписки:** Возможность подписаться на конкретного автора клипов для формирования персональной ленты.

### 5.2. Контент и Лента
-   **Лента видео:** Бесконечный скролл с автоплеем.
-   **Рекомендации:** Алгоритм подбора клипов на основе подписок и лайков пользователя.
-   **Фильтрация и сортировка:** По играм, периодам (день/неделя/месяц), популярности и новизне.
-   **Поиск:** Глобальный поиск по названиям, тегам и авторам.

### 5.3. Взаимодействие и Социальные функции
-   **Оценки:** Система лайков и дизлайков для каждого клипа.
-   **Комментарии:** 
    -   Древовидная структура (ответы на комментарии).
    -   Возможность редактирования и удаления своих комментариев.
-   **Чат:** Интеграция оригинального чата Twitch, привязанного к моменту записи клипа.
-   **Переход на Twitch:** Прямая ссылка на оригинальный канал стримера.

### 5.4. Система репутации
-   **Репутация стримера:** Динамический рейтинг, рассчитываемый на основе:
    -   Количества просмотров клипов на платформе.
    -   Соотношения лайков и дизлайков.
    -   Активности аудитории в комментариях.
-   **Визуальные бейджи:** Статусы (Legend, Pro, Rising Star и прочие, с уникальными фишками статуса) в зависимости от рейтинга.

### 5.5. Администрирование и Монетизация
-   **Рекламный модуль:** Возможность вставки рекламных баннеров или видео-вставок между клипами в ленте.
-   **Панель администратора:** Управление рекламными кампаниями, модерация комментариев и блокировка нарушителей.

## 6. Технические особенности
-   **Twitch API:** Использование эндпоинтов `/clips` для получения данных.
-   **Twitch Embed:** Использование `parent` параметра для корректной работы iframe на домене.
-   **Производительность:** C++ бекенд должен обеспечивать минимальный пинг при подгрузке метаданных для бесконечной ленты.

## 7. Риски
-   **Лимиты API:** Необходимость агрессивного кэширования данных о клипах.
-   **Модерация:** Риск появления токсичного контента в комментариях (требуется фильтр слов).
