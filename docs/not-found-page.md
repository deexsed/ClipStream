# Страница 404

Неизвестные frontend-маршруты показывают страницу «Кажется, мы сбились с эфира»
в общей оболочке ClipStream. Ссылки «На главную» и «Смотреть тренды» используют
client-side navigation, без полной перезагрузки приложения.

`frontend/src/features/errors/NotFoundPage.jsx` и его CSS загружаются отдельным
lazy-модулем только при открытии неизвестного маршрута. Иллюстрация состоит из
HTML, CSS и inline SVG; видео, растровые изображения, дополнительные шрифты,
API-запросы и новые зависимости для неё не используются. Общая оболочка сохраняет
свои обычные запросы сессии и конфигурации.

Индикатор сигнала анимирует только opacity: три цикла по 900 мс, затем остаётся
неподвижным. При `prefers-reduced-motion: reduce` анимация отключена. Содержимое и
ссылки доступны сразу; страница поддерживает обе темы и узкие экраны.

Это экран SPA: HTTP-статус при прямом открытии адреса определяется конфигурацией
веб-сервера и не изменяется React-компонентом.
