# Отклик элементов управления

Общий слой `frontend/src/styles/interactions.css` подключён в `main.jsx` для всех маршрутов, админки и portal/dialog. Он охватывает нативные кнопки, ссылки с href, поля и элементы с интерактивными ARIA roles. Новым стандартным элементам не нужен отдельный класс для подключения отклика.

- Нажатие указателем: scale 0.97 для кнопок, 0.985 для ссылок и крупных строк; реакция начинается на pointer-down через :active, 70 ms, возврат 180 ms. Используется отдельное CSS-свойство scale, чтобы сохранить позиционирование через transform.
- Наведение: подсветка кнопок, навигации, ссылок и карточек, границы полей, ring у checkbox/radio. Hover применяется только при hover:hover и pointer:fine.
- Клавиатура: focus-visible, без масштабирования при нажатии. Выбранные кнопки и активная навигация сохраняют подсветку при hover.
- Disabled/aria-disabled и busy исключены из анимации нажатия; предусмотрены соответствующие курсоры. Реальную блокировку действий по-прежнему обеспечивает компонент.
- Reduced motion отключает переходы и scale; outline и цвета остаются доступны.

Контент стороннего Twitch iframe управляется самим Twitch. Этот CSS действует на интерфейс ClipStream, включая все маршруты и будущие стандартные controls, но не проникает в сторонние iframe.

Проверка 14.11.2026: 47/47 frontend-тестов, production Vite и Docker frontend builds. В браузере на странице трендов проверено применение общего transition ко всем 183 controls; в консоли персонала — ко всем 10 controls основного содержимого. Также проверены профиль/настройки, меню и языковое модальное окно. Изменения пользовательских настроек и модерационные действия для проверки оформления не выполнялись.
