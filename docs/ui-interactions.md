# Отклик элементов управления

Общий слой `frontend/src/styles/interactions.css` подключён в `main.jsx` для всех маршрутов, админки и portal/dialog. Он охватывает нативные кнопки, ссылки с href, поля и элементы с интерактивными ARIA roles. Новым стандартным элементам не нужен отдельный класс для подключения отклика.

- Нажатие указателем: scale 0.97 для кнопок, 0.985 для ссылок и крупных строк; реакция начинается на pointer-down через :active, 100 ms, возврат 160 ms. Используется отдельное CSS-свойство scale, чтобы сохранить позиционирование через transform.
- Наведение: подсветка кнопок, навигации, ссылок и карточек, границы полей, ring у checkbox/radio. Hover применяется только при hover:hover и pointer:fine.
- Клавиатура: focus-visible, без масштабирования при нажатии. Выбранные кнопки и активная навигация сохраняют подсветку при hover.
- Disabled/aria-disabled и busy исключены из анимации нажатия; предусмотрены соответствующие курсоры. Реальную блокировку действий по-прежнему обеспечивает компонент.
- Reduced motion отключает переходы и scale; outline и цвета остаются доступны.

Контент стороннего Twitch iframe управляется самим Twitch. Этот CSS действует на интерфейс ClipStream, включая все маршруты и будущие стандартные controls, но не проникает в сторонние iframe.

Проверка 14.11.2026: 47/47 frontend-тестов, production Vite и Docker frontend builds. В браузере на странице трендов проверено применение общего transition ко всем 183 controls; в консоли персонала — ко всем 10 controls основного содержимого. Также проверены профиль/настройки, меню и языковое модальное окно. Изменения пользовательских настроек и модерационные действия для проверки оформления не выполнялись.

## Футер и доступ к документам

Футер ClipStream расположен после содержимого главной, трендов, каталога и страниц категорий. В нём доступны условия использования, политика конфиденциальности и страница с документами и контактами. Ссылка «Документы и контакты» также доступна на всех маршрутах в боковой панели, в том числе в свёрнутой панели и мобильном меню.

## Единая главная лента

Главная показывает одну сетку клипов. По умолчанию используется серверная смешанная
подборка рекомендаций; «Новая смесь» явно начинает новую сессию. Фоновое обновление
и загрузка следующей страницы не переставляют уже показанные карточки.

Прокрутка запускает следующую загрузку, когда до последнего ряда остаётся
около 10 px. В DOM остаются видимые ряды, по одному соседнему ряду сверху и
снизу и ряд с текущим фокусом. Данные загруженных страниц сохраняются для
возврата прокруткой. При ошибке доступен ручной повтор, а в браузерах без
`IntersectionObserver` — кнопка «Показать ещё».

Категория, период и сортировка применяются к этой же сетке, сохраняются в URL
и доступны через историю браузера. Категории из истории и названия категорий на
карточках главной работают как фильтры. Явные фильтры используют каталог `/clips`
с выбранным порядком (по умолчанию популярность); сброс возвращает смешанную выдачу
и сохраняет поиск и языковые параметры. Карточки отображаются только в обычном крупном виде, без переключателя плотности.

Сворачиваемый график «Состав подборки» считает категории только среди загруженных
клипов. Он не представляет весь каталог или аудиторию Twitch.

Белый бейдж «Новое» расположен слева сверху на превью, если с `twitch_created_at`
прошло менее 24 часов. Время SQL без часового пояса трактуется как UTC. Дата импорта
`created_at` не используется для бейджа; неизвестные, некорректные и будущие даты
его не получают. На открытой странице бейдж исчезает по достижении суток.

Частая фильтрация и значения графика меняются без декоративных переходов. Контролы
используют общие motion-токены: обратная связь при нажатии 100 мс, возврат 160 мс,
Select 180 мс от точки открытия. Клавиатурный ввод и reduced motion отключают
пространственные переходы. Панель фильтров — компактная строка без подложки и повторного заголовка.
Для гостя показана общая лента «Клипы», без заявлений о персонализации и пустых
категорий из истории. На узком экране фильтры прокручиваются по горизонтали,
основные контролы имеют высоту не менее 44 px.
