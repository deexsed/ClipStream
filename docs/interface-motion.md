# Отклик и анимации интерфейса

Общие параметры находятся в `frontend/src/styles/interactions.css` и используют существующий `--ease`. Новые компоненты должны использовать эти параметры, а не собственные значения.

| Действие | Появление / отклик | Закрытие |
| --- | --- | --- |
| Нажатие / отпускание кнопки | 100 / 160 ms | — |
| Цвет состояния | 140 ms | — |
| Список выбора | 180 ms | Мгновенно, с освобождением фокуса |
| Встроенные элементы редактора, подтверждение | 180 ms | 140 ms |
| Диалог, боковое обсуждение | 250 ms | 180 ms |
| Мобильная навигация, нижняя панель | 300 ms | 200 ms |

`Dialog` сохраняет нативное управление фокусом и модальностью. Содержимое остаётся на месте до завершения закрытия; повторное открытие продолжает движение из текущей позиции. `Reveal` делает то же для встроенных блоков, но сразу исключает закрывающийся блок из взаимодействия через `inert` и `aria-hidden`.

После закрытия `Dialog` размонтирует содержимое, освобождая в том числе блокировки вложенного Select. При замене одного диалога другим новый наследует исходную кнопку вызова; старый диалог не забирает фокус у новой панели. Размонтирование открытого диалога отменяет переход и освобождает модальность. `onAfterClose` вызывается один раз после нативного закрытия и позволяет передать фокус при смене типа панели. В ClipRush он используется при переходе от нижней панели к боковому обсуждению после изменения ширины окна.

В основном анимируются `transform` и `opacity`. Два исключения нужны для сохранения раскладки: высота встроенного редактора и ширина сетки при открытии боковой панели. При изменении ширины видео остаётся тем же iframe. Поля, счётчики и карточки ленты не получают декоративных последовательных появлений. Вкладки профиля, подписок и консоли используют короткое затухание без перемещения текста.

Клавиатурные действия и системная настройка `prefers-reduced-motion` отключают переходы поверхностей и движение кнопок. Hover-эффекты включаются только для точного указателя с поддержкой hover. Нативные элементы браузера и встроенный плеер Twitch имеют собственные состояния и стили.

## Проверка

- Запустить `npm test` и `npm run build` в `frontend`.
- Проверить повторное открытие диалогов во время закрытия, Escape и возврат фокуса.
- В ClipRush открыть и закрыть обсуждение, раскрыть и отменить ввод; активный iframe должен сохраняться.
- На узком экране проверить навигацию и нижнюю панель, короткое и длинное перетаскивание, отмену жеста, повторное открытие.
- Проверить списки выбора внутри диалога, вкладки и доступность элементов с клавиатуры.
- Повторить с reduced motion. Проверка на физическом телефоне и профилирование кадров требуются отдельно; эмуляция размера экрана их не заменяет.

Проверки интерфейса не требуют отправки комментариев, изменения ролей, удаления данных или применения блокировок к реальным аккаунтам.
