# Общие компоненты интерфейса

Оформление и базовое поведение общего элемента определяются в
`frontend/src/shared/ui/`, а не копируются в каждый экран.

Используйте компоненты из таблицы ниже. Изменения оформления и базового поведения
должны применяться ко всем потребителям. Экран отвечает за данные, права доступа,
маршрут, тексты и предметную логику; компонент — за общий визуальный контракт и
взаимодействие.

| Элемент                                    | Владелец                                                   | Общая ответственность                                                                                             |
| ------------------------------------------ | ---------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Кнопки, ссылки-кнопки, иконки действий     | `Primitives.jsx`                                           | Варианты, busy/disabled, размеры, состояния наведения и фокуса                                                    |
| Диалоги                                    | `Primitives.jsx`                                           | Native dialog, фокус, Escape, возврат фокуса, прерываемая анимация                                                |
| Подтверждение действия                     | `Confirmation.jsx`                                         | Общие кнопки, запрет повторного запроса и закрытия во время выполнения, ошибка с возможностью повторить           |
| Поля, подписи, checkbox                    | `FormControls.jsx`                                         | Оформление, refs и нативные FormData/validation; `Select.jsx` — выбор значения                                    |
| Поиск                                      | `SearchField.jsx`                                          | Иконка, очистка, единый focus ring и клавиатурное поведение                                                       |
| Панели и заголовки секций                  | `Layout.jsx`                                               | Surface с сохранением семантического тега, отступы и адаптивность                                                 |
| Метрики                                    | `Metrics.jsx`                                              | Обычная и компактная сетки, типографика чисел                                                                     |
| Таблицы                                    | `DataTable.jsx`                                            | Нативные table/thead/tbody, плотность, прокрутка; переполненная область доступна с клавиатуры                     |
| Навигация разделов                         | `SectionNav.jsx`                                           | Активный раздел, aria-current, горизонтальная видимость выбранной кнопки                                          |
| Ошибка, загрузка, следующая страница       | `Primitives.jsx`                                           | Статусы и повторная загрузка                                                                                      |
| Пустое состояние и результат операции      | `Feedback.jsx`                                             | Общие оформление и семантика сообщения                                                                            |
| Аватар и строка автора, изображения Twitch | `Primitives.jsx` (`Avatar`, `Identity`), `TwitchImage.jsx` | Fallback аватара, общая компоновка автора, единое преобразование URL медиа; приоритет загрузки задаёт потребитель |
| Внешние ссылки                             | `ExternalLink.jsx`                                         | `_blank`, `noopener noreferrer`, сохранение дополнительных rel, включая sponsored                                 |
| Голоса за клип                             | `features/clips/ClipVoteButtons.jsx`, `useClipVote.js`     | Две плотности кнопок, вход гостя, pending, единое обновление копий клипа в кеше, включая ClipRush                 |
| Ссылка на клип                             | `features/clips/ShareDialog.jsx`                           | Общий диалог и выделение ссылки для копирования                                                                   |

`Button variant="plain"` сохраняет специальное оформление потребителя
(например, вкладки или кнопки видеоплеера). Обычный `Button` сохраняет нативное
поведение submit; вспомогательным действиям внутри формы задавайте `type="button"`.
`variant="plain"` по умолчанию имеет `type="button"`.

Компоненты загружают свои CSS. Не копируйте их базовые правила в экранные стили.
В экранном CSS остаются размещение, предметные варианты и адаптация конкретного
содержимого: например, превращение строк пользователей в карточки на узком экране.

Для компактного действия используйте `Button size="compact"`. Для выбора через
диалог используйте `SelectButton`, чтобы сохранить оформление и состояния
обычного `Select`. Для поля внутри составного элемента используйте
`TextArea appearance="embedded"`. Мобильные размеры и состояния фокуса
задаются владельцем компонента. Для аватаров используйте размеры `Avatar`,
чтобы изображение и текстовая заглушка сохраняли одинаковую геометрию.

## Полный проход по экранам

| Область                          | Проверенные потребители и результат                                                                                                                       |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Оболочка приложения              | Header, sidebar, меню пользователя, языки, уведомления: общий поиск, кнопки, поля, аватары, сообщения                                                     |
| Каталог                          | Лента, тренды, категории, категория, результаты поиска: общие поля фильтров, панели, кнопки и изображения                                                 |
| Просмотр клипов                  | Карточки, страница, ClipRush, комментарии: общие голоса, share dialog, поля, подтверждения удаления, пустые состояния                                     |
| Социальные экраны                | Локальный/Twitch-профиль, обзор, клипы, стена, друзья, подписчики, подписки, история, настройки: общие разделы, метрики, панели, формы и подтверждения    |
| Отслеживание                     | Лента, профили и Twitch-подписки: общая навигация, поиск и состояния                                                                                      |
| Администрирование                | Обзор, пользователи и доступ, жалобы, импорт, реклама, продвижение, система, IP, журнал: общие таблицы, метрики, формы, панели, подтверждения и сообщения |
| Авторизация и служебные страницы | Login, OAuth callback, документы, 404: общие формы, панели, состояния и ссылки-кнопки                                                                     |

Специализированные взаимодействия сохранены: Twitch player, жесты ClipRush,
компоновка комментариев, рекламный creative, графики и карточки каталога.
Логотип, favicon Twitch и рекламное изображение используют обычный `img`:
они не являются изображениями, которым нужен Twitch media proxy. Предметные
списки профилей переиспользуются в social-модуле; их сетевые запросы не переносятся
в универсальные компоненты.

При добавлении экранов сначала проверяйте этот каталог. Новый общий вариант
добавляйте владельцу компонента, а не независимой копией разметки и CSS.

## Поиск

`SearchField.jsx` и `SearchField.css` задают единые оформление, иконку,
фокус, размеры и очистку. Компонент используется в хедере, каталоге
пользователей, поиске языков и подписок Twitch.

```jsx
<SearchField
  aria-label="Найти пользователя"
  placeholder="Имя пользователя или почта…"
  value={search}
  onValueChange={setSearch}
  onClear={() => resetAppliedSearch()}
/>
```

- `value` + `onValueChange(value)` — управляемое поле для фильтров.
- `defaultValue` — начальное значение для поля с собственным состоянием.
- `name` совместим с `FormData`; `ref` указывает на input.
- Кнопка «Очистить поиск» появляется справа при непустом значении. Она не
  отправляет форму и возвращает фокус в поле.
- Escape очищает непустое поле. В пустом поле событие доступно родительскому
  диалогу. Составление текста через IME не прерывается.
- `onClear` позволяет экрану сбросить применённый серверный фильтр.
  Маршрутизация и отправка формы остаются ответственностью экрана.
- `disabled` и `readOnly` запрещают очистку.

Не добавляйте локальные контейнеры поиска с собственной рамкой или правилами
фокуса input. В экранных стилях допускаются размещение, ширина и внешние отступы.
Фокус задаётся один раз в `SearchField.css`: для input — на внешнем контейнере,
для кнопки очистки — на самой кнопке.
