# Главная страница

Страница `/` называется «Главная» в навигации и ссылках возврата. Отдельный
раздел «Смотреть» удалён; старые адреса `/feed` перенаправляются на `/`
без сохранения параметров удалённой ленты. Просмотр отдельного клипа
по `/clip/:id` и ClipRush доступны как прежде.

Лента использует всю ширину области содержимого. Режимы «Для вас», «Популярное» и «Новое» переключают существующие рекомендации и выдачу клипов. Фильтр языков сохраняется при переключении. Карточки отображаются только в обычном крупном виде. Переключатель плотности удалён, ранее сохранённый компактный режим не применяется.

Карточки используют свободную компоновку: превью со скруглениями, аватар, заголовок и метаданные без общей рамки и фоновой панели. Просмотры Twitch (`view_count`) отмечены иконкой Twitch, просмотры ClipStream (`platform_view_count`) — favicon платформы. Счётчик ClipStream основан на записях `view_history`: это учтённые открытия авторизованными пользователями, включая повторы, а не подтверждённые досмотры видео. Гостевые открытия в существующей истории не записываются.

Кнопки лайка и дизлайка работают прямо на карточке. Повторный голос снимается, противоположный переключает реакцию. Текущий голос подсвечен; пока запрос выполняется, обе кнопки недоступны. Для гостя открывается вход. Ошибка сохраняет предыдущие значения и показывается рядом с кнопками. Успешный ответ обновляет загруженные копии клипа в кеше карточек и страницы просмотра. Счётчик комментариев — ссылка на `/clip/:id#comments`, которая переводит прокрутку и фокус к обсуждению.

Комментарии включают ответы. Счётчики просмотров ClipStream и комментариев загружаются одним SQL-запросом на страницу. Текущие голоса и актуальные итоговые реакции авторизованного пользователя загружаются ещё одним запросом на страницу, включая выдачу из кеша. Остальные счётчики обычной ленты могут храниться в существующем кеше до 60 секунд. Если счётчик отсутствует в ответе API, интерфейс не подставляет ноль.

## Категории из истории

Фильтр «Все категории» открывает панель с поиском по всему загруженному
каталогу и ленивой загрузкой превью. Каталог прокручивается непрерывно,
в четыре колонки на широком экране и в три на телефоне. Панель отрисовывает
видимые ряды и небольшой запас вокруг них. Можно отметить
до 20 категорий и применить выбор одним действием. «Сбросить» снимает отметки
в панели. Escape, клик снаружи и кнопка закрытия отменяют правки.
Плашки над результатами показывают черновик выбора и позволяют снять отметку,
даже если категория скрыта текущим поиском.

На странице `/categories` поиск по названию остаётся доступным при прокрутке.
Страница использует ту же виртуализацию и ищет по всему загруженному каталогу.

Для одной категории URL сохраняет `game_id`, для нескольких используется
`game_ids` со списком через запятую. `GET /clips` принимает один из этих
параметров и возвращает клипы из любой выбранной категории с общей сортировкой
и пагинацией. Остальные фильтры остаются в URL при применении категорий.

Вверху расположены до четырёх категорий «Часто выбираете и смотрите».
Порядок учитывает количество явных выборов категории, открытия клипов
на этом устройстве и серверный `watched_count`. Локальные и серверные открытия
не складываются: используется максимум, чтобы уменьшить двойной учёт.
Открытие клипа не означает подтверждённого просмотра или досмотра Twitch-видео.
При равном количестве локально использованная категория поднимается по времени
последнего выбора/открытия. Без истории персональный блок не показывается.

В localStorage хранятся только ID, счётчики и время последнего использования
до 64 категорий, отдельно для гостя и каждого аккаунта
(`clipstream.category-history.v1.<user-id|guest>`). Текст поисковых запросов
не сохраняется; выбор найденной категории увеличивает её счётчик.
Недоступный или повреждённый localStorage не блокирует выбор категорий.

`GET /games?personalized=1` возвращает до 10 категорий из истории просмотров текущего авторизованного пользователя. Идентификатор берётся из проверенной сессии; параметр `user_id` не используется. Порядок: количество просмотров, затем последний просмотр и ID категории. Удалённые и скрытые клипы не участвуют. Повторные просмотры учитываются как отдельные записи истории.

Для гостя и пользователя без истории список пуст. Главная показывает пояснение и ссылку «Все категории», не подменяя личные категории общим рейтингом. При ошибке загрузки доступен повторный запрос. `GET /games` сохраняет прежнюю выдачу каталога.

Персональная выдача имеет отдельный React Query key с ID пользователя и запрашивается заново при возвращении на страницу.

При оформлении использован [emil-design-eng](https://github.com/emilkowalski/skills/blob/main/skills/emil-design-eng/SKILL.md): адаптивная компоновка, видимый keyboard focus, состояния выбора и существующая система коротких отзывчивых взаимодействий без декоративного появления каждой карточки.
