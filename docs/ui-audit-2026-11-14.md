# Проверка интерфейса — 14.11.2026

Проверен запущенный Docker frontend во встроенном браузере, с реальным сеансом владельца. Размеры viewport: 1440×900, 390×844 и 320×740. Для ClipRush дополнительно проверены 1366, 1024, 1001 и 768 px.

Матрица содержит 47 состояний маршрутов на каждой основной ширине: главная, тренды, категории и категория, просмотр и отдельный клип, ClipRush, три раздела отслеживания, девять вкладок своего профиля, профиль стримера, алиасы профилей, пять юридических документов и их список, callback с действующим сеансом, redirect и 404. Включены все девять разделов `/admin` и шесть `/staff`.

Для каждого состояния проверены загрузка, горизонтальное переполнение документа и основного контейнера, применение общего слоя взаимодействий, доступность центров видимых controls через hit testing. Проверка учитывает clipping внутри горизонтально прокручиваемых списков. Скрипт измерений и результаты сохранены локально в игнорируемом `temp`.

Дополнительно вручную проверены: клик с удержанием у края кнопки, переключение вкладок, меню роли без изменения роли, рекламная форма и её прокрутка до кнопки сохранения, popup внутри dialog, повторные открытия и Escape, комментарии ClipRush справа / в sheet, поиск мышью и клавиатурой. Кампании, комментарии, роли и блокировки не изменялись.

Исправления:

- Текстовое поле поиска получало две обводки после клика. Pointer focus теперь использует спокойную границу контейнера; клавиатурный фокус остаётся заметным. Обычный ввод и движение курсора внутри текста не меняют modality на keyboard.
- Удалена постоянная подсказка `⌘ K`. Поиск использует Ctrl+K на Windows/Linux и Meta+K на Apple; физический KeyK учитывает другую раскладку. Комбинация не уводит фокус за открытый dialog.
- На 320 px кнопки предыдущего/следующего клипа выходили за контейнер. Строка теперь переносится, сохраняя размеры targets.
- Закрытый Select мог зависнуть после Escape при смене pointer на keyboard во время exit animation. Закрытая popup теперь сразу скрывается и освобождает focus/pointer locks. Три последовательных цикла внутри рекламной формы прошли; фокус возвращается на trigger, dialog остаётся открыт.
- На границе 1001 px боковые комментарии ClipRush сжимали видео до 390 px, заставляя Twitch embed сменяться внешним превью. До 1024 px обсуждение теперь открывается в sheet; desktop 1024 px сохраняет панель справа.

После исправлений в проверенной матрице нет горизонтального переполнения и обнаруженных перекрытых центров клика. Проверены production Vite/Docker builds, Prettier и 62 frontend-теста. Новые регрессии охватывают modality, platform modifier, раскладку, отсутствие kbd и сохранение фокуса внутри modal.

Ограничения: viewport-проверка не заменяет физические iOS/Android устройства, мобильную клавиатуру и профилирование кадров. Сторонний Twitch iframe управляет собственными controls; при доступной ширине меньше 400 px используется предусмотренный внешний переход. Во время параллельного пересоздания единственной frontend-реплики две навигации получили 502 и были успешно повторены после её запуска; это окно развёртывания, а не эффект UI. Zero-downtime deployment и HA storage этой проверкой не подтверждаются.
